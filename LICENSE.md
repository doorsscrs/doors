## 🔍 Troubleshooting & Common Issues

### ❌ Script Doesn't Execute

- Ensure your executor is properly attached to the Roblox process
- Try running your executor as Administrator (Windows)
- Disable antivirus temporarily during injection (add executor to whitelist)
- Verify the Roblox client is fully loaded before executing

### ❌ GUI Panel Doesn't Appear

- Check if `AdminPanel = true` is set in your config
- Try toggling the keybind (default varies by executor — check documentation)
- Re-execute the script if the panel fails to render on first inject

### ❌ Auto Rooms Stops Progressing

- This usually indicates a server lag issue — increase `RoomDelay` to `1.5`
- Rejoin the session and re-execute
- Ensure you're not in a private server with custom room rules

### ❌ Entity Spawner Causes Crash

- Reduce `MaxEntities` to 1 or 2
- Disable spawner past room 45+ (known edge case in current version)
- Update to the latest version via the download link

### ❌ Badges Not Being Collected

- Enable `TargetAll = true` and `SkipCompleted = true` in badge config
- Some badges require specific in-game conditions — check the changelog for notes
- Run in a solo or private server for best badge automation results
